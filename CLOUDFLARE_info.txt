2. SECURITY - OBOJE DOMÉNY
------------------------------------------------------
Email Address Obfuscation: VYPNUTO (!)

  DŮVOD: Web používá vlastní JavaScript obfuskaci
  kontaktů (email, telefon) v souboru script.js.
  Cloudflare Email Obfuscation přepisuje DOM elementy
  a koliduje s naším kódem, čímž rozbíjí JavaScript.

  Cesta: Security → Settings → Email Address Obfuscation

  POZOR: Toto nastavení je PER DOMÉNA - musí být
  vypnuto zvlášť pro maxferit.cz i maxferit.com!

------------------------------------------------------

  Cesta: Speed → Settings → Content Optimization

------------------------------------------------------
4. DŮLEŽITÉ POZNÁMKY K JAVASCRIPTU
------------------------------------------------------
Cloudflare Pages automaticky přidává hlavičku:
  Content-Security-Policy: script-src 'self'

To znamená:
  - NESMÍ se používat inline <script> tagy v HTML
  - Veškerý JavaScript MUSÍ být v externím souboru
    (script.js) a odkazovaný přes <script src="script.js">
  - Inline onclick="" atributy NEFUNGUJÍ - vše přes
    addEventListener v externím JS souboru

7. TROUBLESHOOTING
------------------------------------------------------
Pokud po deployi nefunguje JavaScript:
  1. Zkontroluj Console (F12) na CSP chyby
  2. Ověř, že NENÍ inline <script> v index.html
  3. Ověř, že Email Obfuscation je VYPNUTÁ (obě domény)
  4. Purge cache: Caching → Configuration → Purge Everything
  5. Testuj v anonymním okně prohlížeče

Pokud se změny neprojeví:
  1. Zkontroluj deploy v Cloudflare: Workers & Pages →
     maxferitcz-web → Deployments
  2. Purge cache (viz bod 4 výše)
  3. Zapni Development Mode: Overview → Quick Actions →
     Development Mode (dočasně obejde cache)
